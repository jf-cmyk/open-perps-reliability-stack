## Loop Resolution Rule

Each material run must do exactly one of the following:

- verify a fact;
- close an evidence gap;
- change an opportunity score;
- produce a bounded technical implication;
- reject a weak opportunity;
- promote a stable conclusion into a checkpoint.

Afterward, update the queue and select the highest-value unresolved item. The loop should not create new questions faster than it closes them.
