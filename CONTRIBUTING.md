# Contributing

Initial scope is read-only and dry-run only. Do not add production trading, custody, private-key handling, signer automation, or live execution flows without an accepted ADR and founder approval.

Before opening a PR:
- Keep changes scoped.
- Update docs for public interfaces.
- Add tests or fixtures when behavior changes.
- Do not commit secrets, RPC keys, wallet keys, private datasets, or partner-confidential material.
