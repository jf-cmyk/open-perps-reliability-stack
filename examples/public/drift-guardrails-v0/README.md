# Drift Guardrails v0

This package is a scrubbed public example derived from the Drift read-only public-field proof shape. It is intentionally small and only demonstrates public guardrail labels.

It does not contain raw account bytes, RPC credentials, user accounts, positions, market economics, liquidation opportunities, or replay-ready state.

Files:

- `guardrails.json`: public guardrail snapshot records
- `manifest.json`: dataset packaging and source limitations
- `dq.json`: publish gates and scrub status
